## 实际进展

1. 完成 K-Means 聚类分析。

- 使用评分（rating）和消费价格（cost）作为主要聚类特征
- 通过轮廓系数比较不同 K 值，最终确定最佳聚类数量为 K=5
- 对不同聚类进行商家数量、评分、消费水平和餐饮类型分析
- 输出各类商家的消费画像结果

2. 完成聚类结果分析。

- Cluster 0：高评分大众型餐饮，数量最多，消费水平较低
- Cluster 1：低消费基础型餐饮，主要集中在快餐和中餐
- Cluster 2：大众均衡型餐饮，评分和消费处于中间水平
- Cluster 3：高端消费型餐饮，消费价格明显较高
- Cluster 4：中高端品质型餐饮，消费水平和评分较稳定

3. 完成消费预测模型。

- 构建消费价格预测任务，以 cost 作为预测目标
- 对餐饮类型字段进行 One-Hot 编码
- 使用模型分析餐饮类别、菜品标签等因素对消费价格的影响
- 完成模型评估和特征重要性分析

4. 模型结果：

- Log Cost 基础模型：
  - MAE = 63.26
  - RMSE = 107.16
  - R² = 0.0133

- 加入 tag_list 特征后：
  - MAE = 58.97
  - RMSE = 102.70
  - R² = 0.0626

加入菜品标签信息后，模型预测效果有所提升。

## 遇到的问题与解决

### 问题1：机器学习数据量较少

在模型训练过程中，经过筛选后有效数据只有 218 条，导致模型预测能力有限。

解决方法：
- 对已有字段进行有效筛选
- 增加餐饮类型、菜品标签等特征
- 使用交叉验证提高模型评估稳定性

### 问题2：tag_list 字段读取失败

在进行标签特征分析时出现 KeyError: 'tag_list'

解决方法：
- 检查数据字段名称
- 确认前期数据处理后的字段结构
- 修改读取方式，重新加载包含标签信息的数据集
