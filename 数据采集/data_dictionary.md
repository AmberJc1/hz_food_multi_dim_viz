# 杭州餐饮商家数据集 - 数据字典

> **版本**：v2.0  
> **更新日期**：2026-09-04  
> **数据集名称**：hangzhou_catering_conbined.csv  
> **记录数**：1917条  
> **数据来源**：高德地图 Web服务 API（文本搜索 + 详情查询）  
> **采集范围**：杭州市主要行政区（上城、拱墅、西湖、滨江、萧山、余杭等）  

---

## 字段说明

| 字段名 | 中文名称 | 数据类型 | 是否必填 | 取值范围 / 示例 | 来源 | 备注 |
|--------|----------|----------|----------|----------------|------|------|
| `id` | 商家唯一标识 | STRING | 是 | `"B0I07DLSY0"` | 高德API | POI 全局唯一 ID |
| `name` | 餐厅名称 | STRING | 是 | `"很久以前羊肉串(杭州来福士店)"` | 高德API | 含分店后缀 |
| `address` | 详细地址 | STRING | 是 | `"新业路228号来福士6层"` | 高德API | 门牌号及楼层 |
| `adname` | 所属行政区 | STRING | 是 | `"上城区"` | 高德API | 杭州市区级行政区划 |
| `location` | 经纬度 | STRING | 是 | `"120.212917,30.249512"` | 高德API | 格式："经度,纬度" |
| `type` | POI 分类 | STRING | 是 | `"餐饮服务;中餐厅;火锅店"` | 高德API | 分号分隔的三级分类 |
| `typecode` | 分类代码 | STRING | 是 | `"050117"` | 高德API | 高德 POI 分类编码 |
| `tel` | 联系电话 | STRING | 否 | `"0571-86892889"` | 高德API | 多号码以分号分隔 |
| `atag` | 菜品/标签 | TEXT | 否 | `"牛肉,双人餐,烤肉"` | 高德API | 推荐菜或特色标签 |
| `rating` | 综合评分 | FLOAT | 否 | `4.5` | 高德详情API | 范围 0.0 ~ 5.0 |
| `cost` | 人均消费（元） | FLOAT | 否 | `87.00` | 高德详情API | 部分高端餐厅数值较高 |
| `collect_date` | 采集日期 | DATE | 是 | `"2026-09-04"` | 系统生成 | 采集执行日期 |
| `source` | 数据来源 | STRING | 是 | `"amap"` | 系统生成 | 固定值 "amap" |

## 数据质量说明

- **完整性**：`rating` 覆盖率 > 99%，`cost` 覆盖率 > 98%
- **重复率**：< 1%（已按 `id` 去重）
- **采集规则**：分页（每页25条），每个关键词最多5页，请求延时0.5秒，重试3次
- **采集日期**：2026-09-01 至 2026-09-04
